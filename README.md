# auto_tests_ts

A TypeScript/Playwright Test learning port of [`cms-autotests`](https://github.com/) (a Python/pytest/Playwright test-automation project), built as a portfolio artifact. It rebuilds the same core ideas — registry-driven parametrized testing, Page Object Model, fake-data-as-schema, cleanup stack, reference-data cache — using idiomatic TypeScript tooling (Playwright Test, zod, `@faker-js/faker`, Biome, pnpm), improving on the original where the TS ecosystem allows it.

See `PLAN.md` for the full implementation plan and architecture notes.
